# IDT and exception handling

256-entry IDT. Gates 0 to 31 (exceptions), 32 to 47 (PIC IRQs) and 0x81 (a DPL 3 software-interrupt test gate) are
present; all are 64-bit interrupt gates (type 0xE, interrupts disabled on entry) with selector 0x08. Everything else is
not present and faults with #GP if used.

## Stubs

`arch/x86_64/isr.S` is generated by `scripts/gen_isr.py`, which reads the error-code vector list (8, 10 to 14, 17, 21, 29,
30) from `src/idt.rs`, so Rust and assembly cannot disagree silently (`check_asm.py` re-runs the generator and compares).
Each stub pushes a zero when the CPU pushes no error code, then the vector, then jumps to `isr_common`, which saves 15
general registers, aligns the stack to 16, runs `fxsave`, clears DF, calls `omni8_trap_dispatch(frame)`, restores
everything and returns with `iretq`. The frame is 22 qwords (176 bytes); a test pins every offset.

## IST

IST1 fatal exceptions, IST2 #DF, IST3 NMI, IST4 #MC, IST5 IRQs and the 0x81 gate. Using an IST for every gate means an
exception cannot land on a corrupt or nearly full kernel stack and cannot clobber a red zone.

## Dispatch

1. Timer (vector 0x20): count a tick, send EOI, return.
2. Other PIC vectors: treated as spurious (only IRQ0 is unmasked), acknowledged and counted.
3. Vector 0x81 from ring 3: record it and return.
4. A probe the self-test armed, from ring 0: record vector, error code and CR2, then rewrite the frame so execution
   resumes after the probed instruction (`probe.S`).
5. Anything else is fatal: print a deterministic report and halt.

```
OMNI8 FATAL EXCEPTION vector=14 name=#PF page fault err=0x0000000000000005
OMNI8   page-fault: read protection user cr2=0x0000000000100000
OMNI8   rip=… cs=0x0023 ring3 rflags=… rsp=… ss=…
OMNI8   rax=… (register dump, cr3)
OMNI8 FAIL: unexpected exception
```
With `--test-exit` the kernel then writes 0x11 to the debug-exit port.

## Status

Implemented and compiled; layout, gate encoding, error-code table, page-fault decoding and report format are
unit-tested. **No exception has been delivered by a CPU in this environment.**
