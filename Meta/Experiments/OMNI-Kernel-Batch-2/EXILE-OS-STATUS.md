# Exile OS integration status

This directory contains the experimental OMNI-Kernel Batch 2 package.

- Hosted core abstractions and test harness only.
- Not a bootable kernel; no kernel image is produced.
- Not integrated into the Exile OS build.
- Does not replace or modify Kernel/ or ExileKernel/.
- Original package files and manifest are preserved.
- Zig 0.15.2 verification remains pending on the receiving machine.
