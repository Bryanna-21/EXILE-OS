# Exile OS

**Organization:** Exile Organization
**Foundation:** Exile Foundation
**Status:** Independent operating-system project.

Exile OS is developed under Exile Organization as an independent
operating-system project focused on user control, privacy, performance,
extensibility, and integration with the Exile ecosystem.

The project originated from the SerenityOS codebase. Applicable upstream
licenses, copyright notices, and attribution are preserved.

Public-facing branding uses **Exile OS**. Technical identifiers are migrated
deliberately when compatibility and build requirements allow.
