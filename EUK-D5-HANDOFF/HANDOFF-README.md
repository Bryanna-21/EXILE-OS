This package preserves the original host tests, test harnesses,
kernel build outputs, logs, specifications, reports and provenance.

canonical source already exists in ExileKernel/.

The supplied build records describe host-target builds. They do not
establish QEMU or hardware validation.

The original D5 diff is preserved for historical reference and must
not be blindly applied to the canonical source.
